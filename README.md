# Challenges 🚀

Repositório destinado ao registro e organização de desafios, exercícios e problemas de programação, dados, machine learning, segurança e lógica.

O objetivo é centralizar diferentes desafios práticos utilizados para **aprendizado, prática e evolução técnica**.

## 📂 Estrutura

```text
challenges/
│
├── beecrowd/
├── hackerrank/
├── tryhackme/
└── deep-ml/
```

Desafios de programação e resolução de problemas, envolvendo principalmente:

* Algoritmos

* Manipulação de strings
* SQL
* Problemas de otimização

## 🎯 Objetivo

Este repositório funciona como um **portfólio de prática técnica**, reunindo diferentes tipos de problemas e soluções desenvolvidos ao longo dos estudos.

A organização por plataforma permite acompanhar a evolução em diferentes áreas:

| Área                     | Plataforma |
| ------------------------ | ---------- |
| Programação e algoritmos | Beecrowd   |
| Programação e SQL        | HackerRank |
| Cyber Security           | TryHackMe  |
| Machine Learning         | Deep-ML    |

## 🛠️ Tecnologias

Dependendo do desafio, podem ser utilizadas diferentes tecnologias e linguagens, como:

* Python
* C / C++
* SQL
* JavaScript
* Linux / Bash
* NumPy
* Machine Learning
